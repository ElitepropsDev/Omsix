# OMSIX — Digital Solutions & Business Growth Platform

A modern, high-performance landing page built for **OMSIX**. Designed to deliver a premium user experience through sleek dark-mode aesthetics, custom radial ambient glows, glassmorphism UI elements, smooth micro-interactions, and Framer Motion animations.

![OMSIX Preview](/src/assets/business-growth-dashboard.png)

---

## 🌟 Overview

OMSIX unifies three core capabilities under one roof:
* **💻 Digital Solutions**: Websites, Web Applications, Business Systems, Online Stores, Customer Portals, and Automations.
* **📈 Business Development**: CAC Setup, Business Strategy, Process Digitalization, and Operational Support.
* **🎨 Creative & Media**: Brand Identity, Visual Design, Content Creation, and Performance Marketing.

---

## 🚀 Tech Stack

* **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Animations:** [Framer Motion](https://www.framer.com/motion/)
* **Icons:** [Lucide React](https://lucide.dev/)

🛠️ Getting Started
1. Prerequisites
Ensure you have Node.js (v18.0 or higher) and npm installed on your machine.

2. Installation
Clone the repository and install dependencies:

git clone (https://github.com/ElitepropsDev/Omsix.git)
cd omsix-website
npm install

3. Development Server
Start the Vite local development server:

npm run dev

Open your browser and navigate to http://localhost:5173.

4. Build for Production
Create an optimized production bundle:

Bash
npm run build

🎨 Design System Principles
Base Color: Deep Onyx Space (#07050a / #080511)

Accents: Neon Pink (#EC4899), Crimson Red (#EF4444), and Purple (#A855F7)

Glassmorphism: Light white translucency (rgba(255, 255, 255, 0.05 - 0.15) backdrop blur)

Typography: Clean sans-serif with tight letter-spacing (tracking-tight)
